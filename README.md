# mnblzs

**硬件设计 · 电机驱动 · 机器人系统**

围绕机器人与嵌入式设备做板级硬件，记录从原理图、PCB设计到调试验证的实践。关注电源、驱动与接口之间的配合，也把整理后的设计文件和经验分享出来。

[项目作品集](https://github.com/mnblzs/resume-portfolio/blob/main/portfolio/portfolio.md) · [作品集 PDF](https://github.com/mnblzs/resume-portfolio/blob/main/portfolio/portfolio.pdf) · [立创开源硬件](https://oshwhub.com/donnan)

## 关注方向

| 方向 | 主要内容 |
| --- | --- |
| 电机驱动 | FOC驱动硬件、三相功率桥、栅极驱动与电流采样 |
| 机器人与嵌入式控制 | STM32 / CH32控制板、传感器接口、板间通信与系统集成 |
| 电源与储能 | 多路电源树、升降压供电、超级电容储能与保护、电池管理 |
| 接口与PCB | USB信号调理、CAN / RS485 / 串口、PCB布局布线与硬件调试 |
